# Petualangan Domi

Game tebak-tebakan kisah Alkitab untuk anak-anak. Bantu Domi si domba kecil melewati pulau-pulau cerita Alkitab, jawab tebak-tebakan, kumpulkan bintang, dan hias Domi.

Game ini dibuat untuk anak-anak agar memahami Alkitab dengan mudah dari permainan berbentuk quiz dengan tampilan yang menarik.

Tertanda,
**I Made Boby** – Game Development

## Cara main
Buka halaman game di browser HP atau komputer, isi nama dan umur (foto boleh dilewati), lalu tekan **Ayo Main!**

## Catatan
- Nama, umur, foto, dan skor hanya disimpan di perangkat masing-masing pemain (localStorage), tidak dikirim ke server mana pun.
- Musik menu: "Yesus Sayang Padaku" (Jesus Loves Me), William B. Bradbury, 1862, domain publik. Musik permainan: komposisi orisinal.
